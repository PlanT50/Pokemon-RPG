# Pokémon RPG

Um RPG inspirado no universo Pokémon, desenvolvido em Java como projeto de aprendizagem e evolução prática em Engenharia de Software.

## Sobre o projeto

O objetivo é desenvolver um RPG funcional por turnos, começando por uma interface de terminal e evoluindo gradualmente sua arquitetura e funcionalidades.

O desenvolvimento será realizado ao longo de 30 dias, priorizando boas práticas de programação, orientação a objetos, organização de código e controle de versão.

## Funcionalidades planejadas

- [ ] Menu principal
- [ ] Escolha do Pokémon inicial
- [ ] Integração com a PokéAPI
- [ ] Sistema de atributos e tipos
- [ ] Sistema de batalhas por turnos
- [ ] Cálculo de dano e efetividade de tipos
- [ ] Captura de Pokémon
- [ ] Sistema de experiência e níveis
- [ ] Equipe com até 6 Pokémon
- [ ] Inventário básico
- [ ] Salvamento e carregamento de progresso
- [ ] Testes automatizados

## Tecnologias utilizadas

- Java 25
- Maven
- Git e GitHub
- PokéAPI
- Jackson

## Objetivos de aprendizagem

- Aprofundar conhecimentos em Java e POO.
- Aprender a consumir APIs REST.
- Trabalhar com estruturas de dados e coleções.
- Desenvolver sistemas de testes automatizados.
- Aplicar princípios de arquitetura e organização de software.
- Aprender a utilizar Git e GitHub durante o desenvolvimento.
